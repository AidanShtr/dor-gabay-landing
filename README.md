# דף נחיתה — האקדמיה של דור גבאי

דף מכירות לקורס ברברינג ב־8 מפגשים. קהל: חיילים משוחררים וצעירים שרוצים מקצוע
עם הכנסה מהירה. מטרת הדף: לידים חמים.

**חי:** https://aidanshtr.github.io/dor-gabay-landing/

## מבנה

| | |
|---|---|
| `src/index.html` | **קוד המקור.** כאן עורכים. טוען ספריות מ־CDN, נפתח ישר בדפדפן |
| `src/v1-classic.html` | הגרסה הראשונה, גלילה רגילה. נשמרת כגיבוי |
| `vendor/` | הספריות והפונט, שמורים מקומית כדי שהבנייה תהיה זהה תמיד |
| `build.py` | מרכיב מהמקור קובץ אחד עצמאי |
| `index.html` | **התוצר.** זה מה שהשרת מגיש. לא עורכים אותו ידנית |
| `assets/` | תמונות. `og.jpg` ו־`logo-mark.png` נוצרו מהמקור ב־`_logo-src.jpg` |
| `standalone.html` | קובץ אחד עם הכל בפנים כולל התמונות (`build.py --single`) — לשליחה ידנית |

## עדכון הדף

```bash
# 1. עורכים את src/index.html
# 2. בונים מחדש
python3 build.py
# 3. מעלים
git add -A && git commit -m "תיאור השינוי" && git push
```

השרת מתעדכן לבד תוך כדקה.

כשהתוכן האמיתי ייכנס והדף יהיה מוכן לגוגל: `python3 build.py --index`
(מסיר את תגית ה־noindex שמונעת אינדוקס של טיוטה).

## תמונות

`index.html` טוען את התמונות מ־`assets/` כקבצים נפרדים — ככה הדפדפן מוריד אותן
במקביל ושומר אותן במטמון. להחלפת תמונה: לשים קובץ באותו שם ב־`assets/`, לבנות, לדחוף.

`assets/og.jpg` היא התמונה שמופיעה כשמישהו שולח את הקישור בוואטסאפ. 1200×630.

## מה מוטמע בקובץ הסופי

GSAP 3.12.5, ScrollTrigger, Three.js r128, Lenis 1.1.20, והפונט Heebo
(עברית + לטינית, משקלים 400/700/800/900). הדף לא מבצע **אף בקשת רשת** משלו —
עובד גם בלי אינטרנט, וגם אם CDN כלשהו ייעלם.

## עדיין חסר תוכן אמיתי

מספר וואטסאפ (`CONFIG` בראש הסקריפט), מחיר ותנאי תשלום, האם אפשר להשתמש
בפיקדון של חייל משוחרר, עיר/יום/שעה, ביו של דור, תמונות, ועדויות בוגרים אמיתיות.
