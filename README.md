# דף נחיתה — האקדמיה של דור גבאי

טיוטה. דף מכירות לקורס ברברינג ב־8 מפגשים.

`index.html` הוא קובץ עצמאי אחד — כל הספריות (GSAP, ScrollTrigger, Three.js, Lenis)
והפונט מוטמעים בפנים, אפס בקשות רשת.

עדיין ממתין לתוכן אמיתי: מספר וואטסאפ, מחיר, פיקדון חייל משוחרר, מיקום, תמונות ועדויות.
הדף מסומן `noindex` כדי שלא ייכנס לגוגל כל עוד הוא טיוטה.
